# Feature Suggestions for feds.lol

Hey — first time putting in a suggestion here, so wanted to actually write it up properly instead of just dropping a random idea in chat. Mocked a version of this up on the side first to see how it'd feel before bringing it over. Three things:

## 1\. Scroll-snap / scroll-lock

Right now scrolling through a profile is a normal free scroll. I'd love an option where each section snaps into place as you scroll — scroll, it locks to the next section, scroll again, next one — instead of drifting past stuff mid-section. It'd also let sections run longer/taller, since you're not relying on everything fitting before the next section bleeds into view.

## 2\. Movable widgets inside a "bubble" with template layouts

Right now widgets stack as one vertical list you reorder by dragging, same as the Links list. I'd want widgets to live inside a parent "bubble" container that can follow a few different preset templates — a quad grid, a header + single slot, or a header + split two-slot layout — and you place/move widgets around within whichever preset you pick, instead of just reordering a flat list. Same idea as the Layout / Profile Card style pickers you've already got — pick a preset, not a free-form builder.

This would replace the current drag-and-drop layer system, but only for the Widgets section. The Links section's existing layering/reorder system should stay exactly as it is — didn't want that part getting lost in translation.

## 3\. Compact icon-row style for socials ("bubbles")

Also want to suggest a compact icon-row display option for socials/links — small rounded icon buttons in a row instead of the full-width stacked cards. The order you set in the Links list (top to bottom) would just carry over left-to-right in the row. I don't have raw data or code to hand over for this one, just the visual idea — however y'all would want to build it out in your own system/style works.
